# Lit
Lit is a CLI tool for automated Laravel deployments.

In a nutshell: instead of deploying Laravel with `git pull`, you can use `lit pull` instead to make your deployments automated and safer.

## Install
Here's how to install Lit on your server:
```
# Download Lit
git clone git@github.com:SjorsO/lit.git

# Run the interactive installer
bash lit/lit.sh

# Reload your aliases (this will be automated later)
```
